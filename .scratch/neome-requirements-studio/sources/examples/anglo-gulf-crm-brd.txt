How to read this document
Each requirement is numbered, prioritised, scoped and traceable to
where it came from. Anything not yet agreed is an open item, not a

Set out, in testable terms, what the CRM on Neome
must do for Anglo Gulf, based on Anglo Gulf's CRM
expectations deck and Neomenta's clarifications.
Once confirmed, this document is the baseline for
configuration and for user acceptance testing
(UAT).
